# GitHub README setup

1. Keep `README.md` and the `assets/` folder in the repository root.
2. Commit `assets/clausemind-hero.png` along with the README.
3. Replace `YOUR-ORG/YOUR-REPO` in the clone command after creating the repository.
4. Update acknowledgements, licence, screenshots, and tested status with verified details.
5. Never commit secrets, private contracts, `.venv/`, or local databases.
